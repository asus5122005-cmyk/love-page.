# أهلاً يا سندريلا 🎀

صفحة رومانسية ملوّنة بسلسلة أسئلة صغيرة قبل الرسالة:

1. **التاريخ**: تكتب يوم ما اتقابلتوا → **28/2/2025**
2. **سؤال اليوم**: "اليوم كان إيه؟" → **الجمعة**
3. **سؤال القطر**: "معاد القطر كان الساعة كام؟" → **الساعة 12**
4. بعدها صفحة **"أهلاً يا سندريلا"** وزرار **"دوسي هنا عشان تقري الرسالة"**
5. فوق الرسالة سؤال: **"تفتكري إيه أكتر حاجة بحبها فيكي؟"** → الإجابة الصحيحة **"ضحتكِ وروحكِ الطفولية"**
6. بعد الإجابة الصح بتظهر **الرسالة** مع انفجار قلوب 🎉

## التشغيل
افتحي ملف `index.html` بأي متصفح (دبل كليك) — أو زوروا `http://localhost:8123` لو السيرفر المحلي شغال.

## التعديل (كل حاجة في `script.js` أول الملف — كونفج `CONFIG`)
| الحاجة | المكان |
|---|---|
| التاريخ الصحيح | `correctDate: { year, month, day }` |
| أسئلة القفل | `gateQuestions` (سؤال + اختيارات + إجابة + رسائل) |
| كلام صفحة الترحيب | `kicker` / `title` / `subtitle` / `cta` |
| سؤال الرسالة | `loveQuestion` |
| الرسالة | `message` (مصفوفة سطور) |
| التوقيع | `signName` |
| أسباب الحب | `reasons` |
| الفوتر | `footer` |

> بعد أي تعديل: احفظي الملف واعملي refresh للمتصفح.

## نصائح
- للمعاينة بدون أسئلة: `index.html?skip=1`
- القفل والسؤال بيفتحوا تلقائياً في نفس الجلسة بعد مرة واحدة (sessionStorage)
- الصفحة RTL وشغالة موبايل
